# FAQ

## Does the VPK include the original PC game?

No. Install the Vita port, then copy the original PC game's `game/` folder separately.

## Where does the content folder go?

`ux0:/app/RNPYSS002/game/`

## Why extract the VPK instead of installing it directly?

The repository README says direct VPK installation may be slow. It documents VitaShell's **TRIANGLE → More → Install folder** route as a quicker alternative.

## Where do I obtain the original game?

Use the [Steam listing](https://store.steampowered.com/app/1326000/Sakura_Succubus_2/).

## Where should I report a problem?

Open an issue in the [port repository](https://github.com/SilverCrow2323/Sakura-Succubus-2-Vita/issues). Include reproducible steps and paths; do not upload the original game files.
